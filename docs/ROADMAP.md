## Шалгалт

`npm run smoke` — **150 шалгуур**, seed-ээ өөрөө шинэчилдэг тул давтан
ажиллахад найдвартай. Сургууль хоорондын ханыг ч шалгана.

⚠️ Тест **`zulzaga_dev`** санд ажиллана, прод (`railway`) биш. Seed прод санд
ажиллахаас татгалздаг. Прод-д migration: `npm run db:migrate:prod`.

`node scripts/browser-check.mjs` — жинхэнэ Edge хөтчөөр урсгалыг дамжина.
curl-ийн тест хүн юу хараад юу мэдэрснийг шалгадаггүй.
