# Zulzaga EDU V2

1–5-р ангийн сурагч, эцэг эх, багш гурвыг нэг системд холбосон боловсролын платформ.

Энэ бол **V2 — цоо шинээр барих** хувилбар. Хуучин Replit дээрх төслийг зөвхөн
**лавлагаа** болгон ашиглана (санаа, UI, бизнес логик), кодыг нь хуулахгүй.

## Статус

**Phase 0 — Архитектур.** Код бичээгүй. Одоогоор техникийн шинжилгээ, ERD,
эрхийн матриц, MVP хүрээ, аюулгүй байдлын загварыг гаргах шат.
