# Zulzaga EDU V2

1–5-р ангийн сурагч, эцэг эх, багш гурвыг нэг системд холбосон боловсролын платформ.

Энэ бол **V2 — цоо шинээр барих** хувилбар. Хуучин Replit дээрх төслийг
**бүрмөсөн орхисон**, лавлагаа болгож ч ашиглахгүй (2026-09-20).

## Статус

**Phase 0 дууссан** — шийдвэр, өгөгдлийн загвар, эрхийн матриц, задаргаа бэлэн.
Дараагийн алхам: төсөл босгож, даалгаврын гогцоог барих.

Бүтээгдэхүүний чиглэл өөрчлөгдсөн: багш/эцэг эхэд биш, **сургуульд зардаг**
B2B бүтээгдэхүүн. Хичээлийн эрхлэгч багш нэмнэ → багш анги үүсгэнэ → эцэг эх,
сурагчийг урина. Зорилтот хугацаа: **2-р улирал, 2026-11.**
