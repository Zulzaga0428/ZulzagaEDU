# landing-v1 — тэмдэглэл

**Төлөв:** ноорог. Ажиллах төсөлд холбогдоогүй. Zulzaga 2026-09-20-нд
Claude-аар үүсгэж `files.zip`-ээр ирүүлсэн.

Файлууд эцсийн байрлалдаа тавигдсан (`src/app/…`, `public/…`) тул жинхэнэ
Next.js төсөл үүсгэсний дараа шууд зөөгдөнө.

## Сайн байгаа нь

- **Nunito + `subsets: ["latin","cyrillic"]`** — монгол кирилл зөв харагдана
- `<html lang="mn">`
- `manifest.json`, `appleWebApp` metadata — PWA суурь тавигдсан
- `:focus-visible` тойрог ба `prefers-reduced-motion` — хүртээмж бодогдсон
- Бүх өнгө `globals.css`-ийн `@theme` дотор нэг дор
- `RoleCard` зураг олдохгүй бол emoji руу унана (`onError`)
- README нь service worker байхгүйг шулуухан хэлсэн — «Апп суулгах» товч
  Chrome дээр гарахгүй нь үнэн

## ⛔ Шийдвэртэй зөрчилдөж байгаа нь

### 1. Хуудас буруу хүнд хандаж байна

`DECISIONS.md §11`: landing нь **эрхлэгчид** зориулагдана, ганц том товч нь
«Сургуульдаа нэвтрүүлэх».

Одоогийн хуудсанд сургуулийн тухай **ганц ч үг байхгүй**. Эрхлэгч энд орж
ирээд дарах юмгүй. Товчнууд нь «Нэвтрэх» ба «Zulzaga-д нэгдэх».

### 2. Дүр сонгох хэсэг эргэж ирсэн

`DECISIONS.md §12`: дүр сонгуулахгүй, сервер мэднэ.

«Та хэн бэ?» → `/join/teacher`, `/join/parent`, `/join/student` гэсэн 3 карт
байна. Үүнээс гарах гурван зөрчил:

- Эцэг эх урилгын линкээр `/join/<токен>` руу орно — энэ хуудсыг харахгүй
- «Багш → анги үүсгэнэ» гэсэн өөрөө бүртгүүлэх зам нь B2B загварыг зөрчинө.
  Багшийг **эрхлэгч нэмнэ**, багш өөрөө бүртгүүлэхгүй
- Сурагч энэ хуудсаар дамжихгүй — эцэг эх/багшаас код авна

### 3. `layout.tsx`-ийн metadata хуучин түүх ярьж байна

> «Багш анги үүсгэж, эцэг эх QR-аар нэгдэж…»

Энэ бол `BRIEF.md`-ийн 2025 оны багш-төвтэй загвар. `DECISIONS.md §1`-ээр
орлогдсон.

## Асуух зүйл

**Өнгө:** демо дэлгэцүүд sage ногоон + цөцгий + улбар шар байсан. Энэ код нь
цэнхэр (`#2b85f6`) + navy. Цэнхэр нь боловсролын апп болгоны өнгө — демоны
ногоон нь хамаагүй онцлог байсан.

## Жижиг алдаа

`page.tsx` дэх лого `<img src="/img/logo.png">`-д `onError` байхгүй. Файл
байхгүй үед хуудасны дээд талд эвдэрсэн зургийн тэмдэг гарна. `RoleCard`-д
энэ хамгаалалт хийгдсэн, логод хийгдээгүй.
